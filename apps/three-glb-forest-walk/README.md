# Three GLB Forest Walk

A lightweight Three.js forest path demo that uses a single 1.1MB tree GLB, procedural ground details, and a day/night visual toggle.

## Run

```bash
npm install
npm run dev
```

Open the Vite URL, press `进入林间`, then use pointer-lock movement with the keyboard and mouse.

## Asset

- `public/models/tree.glb` from `tripo_convert_ab25f772-45bf-4357-8287-375c3ab1cb80.glb`

The previous large tree/lavender assets are not included in this version.
